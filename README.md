# Mora

The maintained Mora source now lives in [Knot's `crates/mora`](https://github.com/merely-made/knot-editor/tree/2ecc7939e0e9253f37d1623be685e3441a54c800/crates/mora), alongside its CMUdict and Reference Data consumers.

Mora remains a dependency-free, allocation-free-capable prosody library, version 0.1.0, licensed MPL-2.0. The move preserves source and notices and incorporates this repository's history as a parent of Knot's receiving commit. Published releases and prior commits remain available here. New changes belong in Knot.
